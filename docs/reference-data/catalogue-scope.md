# Périmètre du catalogue de référence

## 1. Véhicules

Hiérarchie recommandée :

`Marque → Modèle → Génération / phase → Version → Motorisation → compatibilités`

Champs à conserver quand ils existent :
- Marque constructeur, nom officiel, alias et nom localisé.
- Modèle, carrosserie / variante, code modèle constructeur.
- Génération, code génération, début et fin de production (année ou dates).
- Version / finition, marché et pays si connus.
- Moteur : code moteur, cylindrée, puissance kW/ch, carburant, aspiration, nombre de cylindres, hybride/électrique, boîte et transmission.
- Année-modèle distincte de l'année de première immatriculation.
- Source, URL, date de consultation, auteur, statut et commentaire.

Dacia, Renault, Peugeot, Citroën, DS Automobiles, Volkswagen, Audi, SEAT, Škoda, CUPRA, Mercedes-Benz, BMW, MINI, Opel, Ford, Fiat, Alfa Romeo, Jeep, Toyota, Lexus, Nissan, Hyundai, Kia, Honda, Mazda, Mitsubishi, Suzuki, Subaru, Isuzu, Volvo, Land Rover, Jaguar, Porsche, Tesla, BYD, MG, Chery, Geely, Haval, Great Wall, DFSK, Dongfeng, Changan, JAC, Foton, Tata, Mahindra, Chevrolet.

## 2. Pneumatiques

### Marques candidates

Michelin, Bridgestone, Goodyear, Continental, Pirelli, Dunlop, Hankook, Yokohama, Toyo, Falken, Nexen, Kumho, Maxxis, BFGoodrich, Firestone, General Tire, Uniroyal, Vredestein, Nokian Tyres, Cooper Tires, Giti, GT Radial, Linglong, Sailun, Triangle, Westlake, Goodride, Roadstone, Laufenn, Apollo, CEAT, MRF, TVS Eurogrip, Kenda, Petlas, Lassa, Tigar, Barum, Semperit, Sava, Debica, Fulda, Matador, Taurus, Riken, Kormoran, Radar, Tracmax, Rotalla, Aplus, Hifly, Arivo, Double Coin, Aeolus, Advance.

À compléter à partir des marques réellement commercialisées par les fournisseurs PNEU MOUHIM. Conserver les graphies de marque distinctes et les alias sans fusion abusive.

### Dimensions et attributs

- Largeur nominale (mm), rapport hauteur/largeur (%), diamètre de jante (pouces).
- Indice de charge, indice de vitesse, indice de charge simple/double si applicable.
- Renforcé XL / Extra Load, C / LT, Run Flat, Seal / self-sealing, homologation constructeur.
- Saison : été, hiver, toutes saisons ; usage : tourisme, SUV/4x4, utilitaire, poids lourd, moto, agricole/industriel si activé.
- Construction (radiale), tubeless / tube type, type de sculpture, gamme et modèle commercial.
- DOT : semaine + année, lot de réception et quantité.
- Pour pneu d'occasion : identifiant individuel, DOT lisible ou inconnu, profondeur en mm, photos, inspection et origine.

Ne pas fabriquer un catalogue de dimensions par simple combinaison mathématique. Une dimension disponible dans le commerce n'est pas automatiquement homologuée pour un véhicule.

### Recherche rapide

Accepter les formats `205/55 R16`, `205 55 16`, `205-55-16`, avec normalisation de recherche, tout en stockant les champs séparés. Rechercher aussi par marque, modèle, indices, saison, XL, Run Flat et référence SKU.

## 3. Huiles et fluides

### Marques candidates

TotalEnergies, Shell, Mobil, Castrol, Motul, Liqui Moly, Elf, Petronas, Valvoline, Fuchs, Gulf, Texaco, Repsol, Mannol, Ravenol, Febi Bilstein, Motorex, Wolf, Bardahl, Kroon-Oil, Q8 Oils, Amsoil, Aral, Yacco, ROWE, Eurol, Selenia, ENI, Champion, Orlen Oil.

### Attributs techniques

- Famille : huile moteur, boîte manuelle, ATF, transmission/différentiel, hydraulique, frein, refroidissement, lave-glace, graisse, additif.
- Viscosité SAE (ex. 0W-20, 5W-30, 10W-40) sans confondre viscosité et homologation.
- API (catégorie exacte), ACEA (séquence exacte), ILSAC, JASO.
- Homologations OEM exactes (ex. VW, MB, BMW, Renault, PSA/Stellantis, Ford, GM, Toyota…), avec version et date si disponibles.
- Type : synthétique, semi-synthétique, minérale ; gamme et nom produit.
- Conditionnement commercial : 1L, 2L, 4L, 5L, 20L, 60L, 208L, etc.
- Fiche technique (TDS), fiche de sécurité (SDS), URL officielle et date de vérification.

**Règle de vente actuelle :** bidons fermés uniquement, unités entières.  
**Évolution future demandée :** gérer en parallèle les bidons fermés et les fûts/vrac avec conversion et traçabilité dédiées, après décision et développement séparés.

## 4. Autres pièces et consommables

Prévoir des référentiels par famille, sans imposer une compatibilité non vérifiée :

- Jantes : diamètre, largeur, entraxe PCD, nombre de trous, alésage central, ET/déport, type de fixation.
- Valves, chambres à air, masses d'équilibrage, mèches, rustines, colles et consommables atelier.
- Filtres : huile, air, habitacle, carburant ; référence OEM et équivalences fabricant.
- Batteries : tension, Ah, CCA, technologie (plomb, EFB, AGM…), dimensions, polarité, norme de mesure.
- Éclairage : culot (H1, H4, H7, H11…), tension, puissance, fonction, technologie.
- Freinage : plaquettes, disques, dimensions et références OEM/équivalentes.
- Essuie-glaces, liquides, additifs et accessoires.

## 5. Prestations atelier

Parallélisme, équilibrage, montage/démontage, réparation crevaison, réparation jante, gonflage azote, vidange, filtres, freins, batteries, réglage des phares, éclairage, permutation, autres.

Chaque prestation peut définir : prix, TVA paramétrable, durée indicative, site, catégories de véhicules, seuils de diamètre, consommables automatiques et forfaits. Les consommables doivent être déduits par mouvements de stock, jamais par modification directe des quantités.

## 6. Expérience de recherche et de saisie

- Recherche tolérante aux accents, casse, espaces, tirets et variantes d'écriture.
- Suggestions dès la saisie et recherche par code/référence/dimension.
- Filtres progressifs : famille → marque → modèle → génération → moteur → année.
- Afficher séparément : confirmé, non vérifié, à contrôler, obsolète.
- Si aucune correspondance : proposer « ajouter une nouvelle entrée » aux personnes autorisées, sans créer automatiquement un doublon.
- Afficher les informations utiles en vente ; masquer les champs techniques avancés dans « Plus de détails ».
- Les résultats doivent montrer les détails qui justifient une compatibilité, pas seulement le nom du modèle.
